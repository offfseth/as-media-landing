# A&S Media Landing Page

One-page marketing site for A&S Media real estate photography and Instagram reels services.

## Local preview

```powershell
python -m http.server 8080
```

Open `http://localhost:8080`.

## Auto deploy

This repo includes a GitHub Actions workflow at `.github/workflows/deploy-pages.yml`.

After the repo is pushed to GitHub and Pages is enabled with **Source: GitHub Actions**, every push to `main` will deploy automatically.
